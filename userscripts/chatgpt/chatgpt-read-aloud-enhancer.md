# ChatGPT 朗读增强助手

文件：`chatgpt-read-aloud-enhancer.user.js`

该脚本增强 ChatGPT 网页版的官方“朗读”功能，不自行生成语音，也不替换 ChatGPT 的声音。它在每条助手回答的一级操作栏末尾增加快捷按钮，并在官方音频真正开始播放后显示紧凑悬浮播放器。

## 主要功能

- 一级“朗读 / 重播”快捷按钮；
- 播放、暂停、进度拖动和时间显示；
- 快退、快进，步长可选 3、5、10 秒，默认 3 秒；
- 播放速度可选 0.75×、1×、1.25×、1.5×、2×；
- 播放上一条或下一条当前可见的助手回答；
- 最小化、关闭和聊天切换状态清理；
- 将当前朗读音频在浏览器本地转换为 MP3 并保存。

## 播放器与快捷键

| 按键 | 功能 |
|---|---|
| `↑` | 播放上一条助手消息 |
| `↓` | 播放下一条助手消息 |
| `←` | 按当前跳转步长快退 |
| `→` | 按当前跳转步长快进 |
| `Space` | 播放或暂停 |
| `Esc` | 关闭播放器并暂停 |

焦点位于输入框、文本域、下拉框或可编辑区域时，脚本不会接管这些快捷键。

## 上一条与下一条

消息列表只在用户点击切换按钮或按下 `↑` / `↓` 时即时扫描，不会持续高频遍历页面。脚本只处理当前页面中可见、带有有效回复操作栏的助手回答。

- 到达第一条或最后一条时停止，不循环；
- 新增消息后会在下一次切换时重新读取；
- 重新回答或切换回答版本后，会按当前可见消息重新计算；
- 切换聊天时会停止并解绑旧聊天中的音频，隐藏播放器并重置消息上下文。

## MP3 下载

点击播放器顶部的下载按钮后，脚本只需要一次启动操作：

1. 在支持 File System Access API 的 Chrome 中，立即打开保存位置选择框；
2. 读取 ChatGPT 当前官方朗读音频；
3. 使用 Web Audio API 解码；
4. 在当前标签页本地转换为单声道、96 kbps MP3；
5. 写入用户选定的文件。若浏览器不支持保存句柄，则回退到普通浏览器下载。

转换期间，下载图标会变成旋转状态，具体阶段和百分比通过按钮 Tooltip 与无障碍标签提供，不再占用播放器顶部的文字空间。转换成功后短暂显示勾号，失败时显示感叹号并在状态区给出简短提示。

音频不会上传到第三方服务器。较长音频的转换会占用一定 CPU 和内存，编码循环会定期让出主线程以减少页面卡顿。

MP3 编码通过 userscript 头部的 `@require` 单独加载 `lamejs-fixed 1.2.2`。该依赖采用 LGPL-3.0 许可，脚本不修改或内嵌其源码：

- 项目：`https://github.com/zhuker/lamejs`
- 加载地址：`https://cdn.jsdelivr.net/npm/lamejs-fixed@1.2.2/lame.min.js`

## 数据与隐私

- 跳转秒数、播放速度和播放器折叠状态仅保存在浏览器 `localStorage`；
- 脚本不保存 ChatGPT 对话正文；
- 脚本不上传朗读音频；
- MP3 解码、编码和保存均在当前浏览器中完成。

## 已知限制

- ChatGPT 页面结构或官方朗读实现变化后，DOM 选择器可能需要更新；
- 官方流式音频刚开始播放时，总时长可能暂时不可用，进度条会在时长可用后恢复；
- 音频源无法被浏览器读取、源格式无法解码或 MP3 编码依赖加载失败时，下载会失败；
- Chrome 的保存位置选择框需要安全上下文和用户手势；不支持该 API 的浏览器会使用普通下载作为后备；
- 长音频转换会短暂占用 CPU 和内存。
