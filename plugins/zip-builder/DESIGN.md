# ZIP Builder · ZTools 内置窗口设计

## 界面

使用 ZTools 内置主窗口（`dist/index.html`）。无重复标题栏，灰黑色中性主题；目录树为主区域，顶部紧凑操作栏，底部单行完整 ZIP 输出路径和打包按钮。所有可见下拉菜单和弹窗自绘，使用本地官方 Lucide SVG。文件树行主体可单击切换勾选，展开箭头、来源的替换/移除按钮独立响应。Esc 逐层关闭菜单或弹窗。

## 来源与选择

- 添加支持多来源；不提供顶部替换入口，统一在各来源根节点行尾操作替换或移除。
- 目录懒加载；选择状态以绝对路径 `overrides` 表示，父级覆盖会清理后代覆盖；自动排除按路径段生效，显式勾选能重新包含。
- 默认 ZIP 名取来源文件夹的末级目录名；多个来源组合名称，较多时采用来源数量摘要。用户手动编辑文件名后不自动覆盖，不提供底部恢复按钮。

## 目录关联方案

- 方案存储 `localStorage` 的 `zip-builder-presets-v2`，从 `v1` 自动读取和内存迁移，保存时转为 `v2`；旧数据保留作回滚。
- 当前实现以聚焦的**单个来源目录绝对路径**为键；同一来源可有多个方案，优先恢复最后一次使用的方案。旧组合记录保留但不进入来源方案列表。
- 再次添加或替换来源时自动查找精确匹配；没有组合方案时，可以借用每个单来源匹配方案的手动选择覆盖规则（不将多个不同方案的全局排除规则混在一起）。
- 支持新建、保存、另存为、重命名和删除。已修改未保存显示提示，不自动修改已保存方案。方案保存来源、覆盖规则、排除规则和 ZIP 文件名，不保存目录扫描结果。
- 输出目录独立持久化至 `zip-builder-output-directory-v1`，作为所有方案共享的本机设置；路径无效会报错而不静默更改。

## 压缩与安全

- 固定 ZIP 格式，低内存流式写入，ZIP64，逐项校验大小与时间；失败或取消清理 `.part`。
- 默认不覆盖同名 ZIP；检测已存在时通过自绘确认弹窗明确授权本次覆盖。先写 `.part`，最后才替换目标文件，不覆盖已存在的 `.part`。
- 多来源顶层同名与路径重叠在压缩规划阶段拦截；不跟随目录链接；输出 ZIP 或其临时文件不会递归进入自身。
- 退出插件取消任务；ZTools 宿主在销毁页面时是否能完成文件句柄清理仍需 Windows 实测。

## 验证

本地执行 `node scripts/typecheck.mjs zip-builder`、`node scripts/build.mjs zip-builder`、`node scripts/check-icons.mjs zip-builder`，并运行 ZIP CRC、同名输出和取消任务测试。静态验证不能代替 Windows ZTools 文件夹对话框、窗口大小、方案恢复和菜单键盘操作验收。

## v0.2.1 交互整理

- 方案下拉菜单只放方案操作，更多菜单只放全局设置和重置；使用 bookmark、save、plus、pencil、trash-2 表达明确语义。
- `removeSubInput()` 隐藏 ZTools 顶部子搜索框，失败则保留宿主默认行为，不注入 CSS。
- 默认保存目录从更多菜单选择并本地持久化；完整路径可以临时编辑，不能在临时输入时覆盖默认目录设置。
- 排除规则无每行边框与分割线；行高紧凑，删除按钮悬停增强。

## v0.2.2 统计行为

- 前端只管理统计调度、状态与短期查询缓存；Preload 调用现有 `planFiles()`，保证排除规则和重新包含行为与真正压缩一致。
- 用户勾选或调整排除规则时，取消前一统计请求；300ms 内合并高频变更。统计中显示**已扫描下界**，不将其误称为最终总数。
- 完成结果按来源与选择规则缓存 20 秒；文件系统外部变动可能导致短时间内统计过期。压缩任务不使用预览缓存，始终实时扫描。
- ZIP 写入时优先运行压缩任务；离开插件或关闭窗口时同时取消后台统计与压缩任务。

## v0.2.3 来源专属方案与常用文件夹

- 方案按当前**聚焦单个来源**的规范化路径过滤；没有来源则清空方案显示并禁用方案操作。多来源的树形勾选依旧完整保留，应用当前方案只替换该根目录的选择覆盖规则。
- 收藏只存路径（`zip-builder-favorite-folders-v1`）；从路径取末级名称，展开菜单显示两行名称和完整路径；使用中文 Collator 的数字自然升序并以路径做同名排序。
- 常用文件夹选择：单来源时替换，多来源时切换聚焦或追加未加载来源。取消收藏不影响任何方案。根目录的「方案」按钮切换聚焦来源，不改变其勾选。
- 保留旧 v1/v2 方案记录；其中单根目录方案继续可用，原组合方案保留但不自动分配给其他目录。全局排除规则仍为共享设置，应用目录方案不修改其他来源的全局规则。
- 移除底部刷新按钮，自动文件名随来源更新，用户手动编辑后不覆盖其命名。

## 清空当前工作区

- 顶部「清空」一次移除全部当前来源、目录树、临时选择和聚焦方案，重置输出 ZIP 的自动命名及大小统计；禁用状态为无来源或正在压缩/读取目录。
- 任何当前来源关联的已保存方案有未保存的勾选修改时，用自绘弹窗确认；普通临时选择则直接清空。
- 清空先取消正在进行的大小统计并使旧异步回调失效；不写入或删除任何本地文件，不修改收藏、已保存方案、全局排除规则或默认 ZIP 保存目录。

## v0.2.5 工具栏

- 顶部保留添加、清空和设置；替换仅通过来源根目录行尾入口进行。
- 清空以柔和红色的 Lucide `trash-2` 表示工作区重置（不删除磁盘文件）；此前的未保存确认规则不变。
- 设置入口采用 Lucide `settings`，其弹出菜单全部采用纯文字选项；生成 ZIP 按钮不再附带图标。

## 方案和收藏下拉框（本轮更新）

- 两者均为自绘可搜索选择器：列表有最大高度，只有列表滚动，顶部搜索框及底部操作区保持固定。
- 方案条目点击即应用；右侧 `···` 在条目下方展开重命名/删除，操作目标通过方案 ID 明确指定，不能默认误操作当前选中方案。
- 方案底部仅保留「保存修改」（已选方案时）和「新建方案」；取消原有随列表增长的多个操作项。
- 收藏按目录名或完整路径筛选，底部收藏入口固定；每条可直接取消收藏，原目录与关联方案不受影响。

## 维护性整理（局部重构）

- 页面拆成 App 布局、目录树、方案选择器及常用目录选择器，共享 `useZipBuilder` 上下文，避免组件间双份状态。
- `dirty` 与清空保护基于当前来源和持久方案的选择差异计算，不再手动维护状态标记。单来源时输出 ZIP 名称的差异也计入未保存修改。排除规则属于全局设置，不随某个来源方案加载而变更。
- `preset-storage.ts` 保持现有 localStorage key 及 v1/v2 结构，不强制数据迁移；已保存来源目录由规范化路径匹配。
- `compileSelection` 在一次规划扫描开始前构建路径覆盖表和排除名称集合，减少重复遍历；ZIP 流式写入实现不变。
- 菜单 CSS 移除部分无效覆盖；不更换 UI 风格。新增 `tests/zip-builder-refactor.test.mjs` 作为相关行为回归测试。

## 轻量化下拉菜单

- 方案列表无数量标题或搜索框，列表可滚动，底部保存、新建为低强调菜单项；条目 `···` 通过 Teleport 浮动菜单提供重命名、删除，避免滚动裁切。
- 常用文件夹无统计标题和选中勾号；右上角 Lucide 搜索图标展开临时搜索输入框，当前目录以轻微行背景提示；取消收藏仍只影响收藏列表。

## 菜单交互精修

- 方案下拉框取消选中勾号，以低对比度背景和“选中”文字标识当前方案；每个方案右侧直接提供重命名与删除图标按钮，不再展开 `···` 二级菜单。
- “保存修改”和“新建方案”在菜单底部同行展示。
- 常用文件夹搜索入口移至菜单底部，与“收藏当前文件夹”同一行；点击搜索后原位切换为输入框及关闭按钮，不再占据独立顶部行。

## 方案菜单交互（精修）

- 当前方案仅用低对比度背景标记，移除“选中”字样。
- 条目右侧直接提供铅笔和删除图标；铅笔在该条目下方显示紧凑内嵌编辑区，保存/取消留在菜单内部。Enter 保存、Esc 取消，校验空名称、80 字符限制和当前来源内重名。
- 菜单底部“保存修改”“新建方案”保持并列，采用轻量描边按钮，不改变方案存储格式或打包逻辑。

- 方案重命名采用 Obsidian 式原位编辑：点击铅笔后名称在原行变为输入框，不新增行或弹窗；Enter 保存、Esc 取消，失焦时有效名称自动保存，非法名称不写入。

## 方案新建交互

「新建方案」应复用 Obsidian 风格的列表内原位输入：单击后在列表顶端插入临时行并自动聚焦，用户直接键入名称；Enter 保存、Esc 取消，失焦时只提交合法名称。禁止弹出新建方案模态框；新建完成后继续显示方案菜单，当前来源及选择快照保持一致，生成的方案成为当前方案。
